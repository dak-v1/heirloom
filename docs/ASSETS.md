# Asset catalogue

All artwork is original and generated by code in `scripts/assets/`, so it can be restyled consistently and regenerated in one command:

```bash
npm run assets       # 2D + 3D
npm run assets:2d    # stamps, badges, brand, decor, icons, textures, share image
npm run assets:3d    # passport + rubber stamp GLB, passport cover PNG
```

Colours come from `scripts/assets/lib/palette.mjs` (mirrors `src/styles/tokens.css`). Text is converted to vector outlines with HarfBuzz (`scripts/assets/lib/fonts.mjs`), so Chinese, Tamil and Jawi render correctly without any installed fonts. Preview contact sheets: `node scripts/assets/dev/_preview-stamps.mjs out.png` (also `_preview-badges`, `_preview-brand`, `_preview-passport`).

## Site stamps — `public/assets/stamps/`

| File | Use |
| --- | --- |
| `<site>.svg` | Full-colour perforated postage stamp: tray, reward, cards, map pins |
| `<site>-ink.svg` | Single-colour rubber-stamp impression with distressed ink, transparent background: what gets pressed onto a passport page (Stage 2) |

- Sites: `thian-hock-keng` (terracotta), `sri-mariamman-temple` (dusty blue), `sultan-mosque` (olive).
- Canvas **300 × 380** (aspect `STAMP_ASPECT` in `src/content/passport.ts`).
- Each stamp: hand-built landmark line art (`scripts/assets/lib/landmarks.mjs`), English name, local-script name (天福宫 / ஸ்ரீ மாரியம்மன் கோவில் / مسجد سلطان), area and number.
- Ink impressions leave a blank **visit-date band**: normalised `{ x: 0.233, y: 0.868, w: 0.533, h: 0.053 }` (also `site.stamp.dateBand`). Print the visitor's date there in CSS; the stamp art never carries a fake historical date.

## Badges — `public/assets/badges/` (240 × 240)

## 3D — `public/assets/3d/`

### `heirloom-passport.glb` (≈ 790 KB, embedded PNG textures)
Units: 1 = 10 cm (88 × 125 mm passport → 0.88 × 1.25), centred at the origin, cover facing +Z.

| Node | Content |
| --- | --- |
| `Passport` | root; `extras.heirloom` holds dimensions and usage notes |
| `BackCover` → `BackCoverFace` | leather board; outer face with blind-embossed mark and "not an official travel document" |
| `PageBlock` | page edges texture; **+Z face is the identity page** (visible when open) |
| `Spine` | leather half-cylinder with gold bands |
| `FrontCover` | **hinge pivot on the spine**; children `FrontCoverBoard`, `FrontCoverFace` (gold-foil cover art), `FrontCoverInside` (Peranakan-tile endpaper) |
| `Ribbon` | mustard bookmark |

- Animation **`Open`** (1.1 s): rotates `FrontCover` 0 → −172° about Y. Play forwards to open, backwards to close (see `Passport3D.tsx`).
- Materials: PBR. Gold foil uses a metallic-roughness map; leather uses a tiled normal map on `TEXCOORD_1`.
- Viewer: `src/features/passport/Passport3D.tsx` (three.js, lazy-loaded; drag to turn, tap to open; reduced motion jumps straight to the end state; falls back to `passport-cover.png` without WebGL).

### `rubber-stamp.glb` (≈ 175 KB)
Wooden rubber stamp: `Pad` (rubber, 0.6 × 0.6, origin at the rubber face centre, +Y up), `Block`, brass `Ferrule`, lathe-turned `Handle`. For a 3D stamping animation; the 2D alternative is `decor/stamp-tool.svg`.

### `passport-cover.png` (440 px)
Flat cover art: Home preview and the no-WebGL fallback.

## Textures — `public/assets/textures/`

`paper-grain.png`: 256 px seamless, transparent grain to overlay on paper surfaces (passport pages). The app background uses an inline SVG noise (`--grain` in `tokens.css`) so it never fails to load.

## Sound

No audio files ship. Soundscapes (`harbour-temple`, `street-bells`, `kampong-morning`) and effects (`playChime`, `playStampThunk`) are synthesised with the Web Audio API in `src/services/audio/`. Prepared narration MP3s, when generated, live in `public/audio/narration/`.
