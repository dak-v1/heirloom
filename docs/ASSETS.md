# Asset catalogue

All artwork is original and generated by code in `scripts/assets/`, so it can be restyled consistently and regenerated in one command:

```bash
npm run assets       # 2D + 3D
npm run assets:2d    # stamps, badges, brand, decor, icons, textures, share image
npm run assets:3d    # passport + rubber stamp GLB, passport cover PNG
```

Colours come from `scripts/assets/lib/palette.mjs` (mirrors `src/styles/tokens.css`). Text is converted to vector outlines with HarfBuzz (`scripts/assets/lib/fonts.mjs`), so Chinese, Tamil and Jawi render correctly without any installed fonts. Preview contact sheets: `node scripts/assets/dev/_preview-stamps.mjs out.png` (also `_preview-badges`, `_preview-brand`, `_preview-passport`).

## Site stamps — `public/assets/stamps/`

| File | Use |
| --- | --- |
| `<site>.svg` | Full-colour perforated postage stamp: tray, reward, cards, map pins |
| `<site>-ink.svg` | Single-colour rubber-stamp impression with distressed ink, transparent background: what gets pressed onto a passport page (Stage 2) |

- Sites: `thian-hock-keng` (terracotta), `sri-mariamman-temple` (dusty blue), `sultan-mosque` (olive).
- Canvas **300 × 380** (aspect `STAMP_ASPECT` in `src/content/passport.ts`).
- Each stamp: hand-built landmark line art (`scripts/assets/lib/landmarks.mjs`), English name, local-script name (天福宫 / ஸ்ரீ மாரியம்மன் கோவில் / مسجد سلطان), area and number.
- Ink impressions leave a blank **visit-date band**: normalised `{ x: 0.233, y: 0.868, w: 0.533, h: 0.053 }` (also `site.stamp.dateBand`). Print the visitor's date there in CSS; the stamp art never carries a fake historical date.

## Badges — `public/assets/badges/` (200 × 200, transparent)

Singapore-themed **enamel pins**, generated by `scripts/assets/lib/pins.mjs`. Each is a die-struck metal shape (gold or nickel) with enamel fields between raised metal lines, an edge for thickness and a gloss highlight, in the shape of its motif:

| Badge | Pin |
| --- | --- |
| `first-footsteps` | shophouse with footprints on the five-foot way |
| `time-traveller` | colonial clock tower |
| `sharp-eye` | magnifier over an old photo of the Singapore River |
| `good-listener` | 1950s cable-radio set with a music note |
| `curious-mind` | Peranakan tile |
| `many-tongues` | speech bubble: hello, 你好, apa khabar, வணக்கம் |
| `three-journeys` | trishaw (three wheels, three sites) |
| `memory-keeper` | red pillar box with a letter going in |

Locked state is CSS (greyscale, faded). What each pin shows and a line of background live in `src/content/badges.ts` (`motif`, `about`) for the profile close-up. Award rules live in `src/services/progress.ts`.

## Avatars — `public/assets/avatars/` (160 × 160, full bleed)

Map icons for the profile, from `scripts/assets/lib/avatars.mjs`: `otter`, `kopi`, `merlion`, `orchid`, `trishaw`, `durian`. Flat colour with ink outlines on a tinted ground. They're drawn to work both cropped to a circle (picker, map marker) and square inside a stamp frame (explorer card, passport photo). Names and one-line notes: `src/content/avatars.ts`.

## 3D — `public/assets/3d/`

### `heirloom-passport.glb` (≈ 1.2 MB, embedded PNG/JPEG textures)
Units: 1 = 10 cm (88 × 125 mm passport → 0.88 × 1.25), centred at the origin, cover facing +Z. The page list, leaf order, identity-field positions and open angle come from **`src/content/passport-layout.json`**. The build script and the app both read it, so they stay in step.

| Node | Content |
| --- | --- |
| `Passport` | root; `extras.heirloom` lists the leaves, page materials and clips |
| `BackCover` → `BackCoverFace` | leather board; outer face with blind-embossed mark and "not an official travel document" |
| `PageBlock` | the remaining sheets under the leaves (page-edge texture on the sides) |
| `Leaf1`–`Leaf4` | **four turnable leaves**, hinged at the spine (local x = 0). Each has a `LeafNRecto` (faces up on the right) and a `LeafNVerso` (shows on the left once turned) |
| `Spine` | leather half-cylinder with gold bands |
| `FrontCover` | **hinge pivot on the spine**; children `FrontCoverBoard`, `FrontCoverFace` (gold-foil cover art), `FrontCoverInside` (Peranakan-tile endpaper) |
| `Ribbon` | mustard bookmark |

- **Pages:** the leaf faces carry the 8 logical pages: `identity`/`p1`, `p2`/`p3`, `p4`/`p5`, `p6`/`end` (recto/verso). Spreads: inside cover + identity, p1 + p2, p3 + p4, p5 + p6. Each face has its own material **`Page:<pageId>`** (720 px JPEG, same templates as the flat book: guilloche, waves, tiles, orchid, shophouses, plain), so the app can find a page and paint stamps onto it.
- **Leaf meshes** are 24-segment strips. Vertices run spine → outer edge as (top, bottom) pairs and the verso mirrors the UVs, so the app can bend them into a paper curl while turning.
- **Animations:** `Open` (1.1 s) rotates `FrontCover` 0 → −176° about Y; `TurnLeaf1`–`TurnLeaf4` are rigid leaf turns for other viewers. The app animates the cover and leaves itself (with curl) and doesn't play these clips.
- Materials: PBR. Gold foil uses a metallic-roughness map; leather uses a tiled normal map on `TEXCOORD_1`.
- **Runtime:** `src/features/passport/three/PassportScene.ts` (cover, curling leaves, camera framing, raycast hit-testing, ghost stamp, rubber-stamp press), `three/pageArt.ts` (paints ink impressions and identity details onto each page texture) and `three/curl.ts` (pure, tested leaf-bending maths), wrapped by `PassportBook3D.tsx` (lazy-loaded). Without WebGL the app falls back to the flat book.
- Preview the page faces: `node scripts/assets/dev/_preview-pages.mjs` writes a contact sheet.

### `rubber-stamp.glb` (≈ 175 KB)
Wooden rubber stamp: `Pad` (rubber, 0.6 × 0.6, origin at the rubber face centre, +Y up), `Block`, brass `Ferrule`, lathe-turned `Handle`. Used by the 3D press in `PassportScene.ts`: the pad lands on the chosen spot, square to the page. The flat book's CSS animation uses `decor/stamp-tool.svg`.

### `passport-cover.png` (440 px)
Flat cover art: Home preview and the no-WebGL fallback.

## Textures — `public/assets/textures/`

`paper-grain.png`: 256 px seamless, transparent grain to overlay on paper surfaces (passport pages). The app background uses an inline SVG noise (`--grain` in `tokens.css`) so it never fails to load.

## Sound

No audio files ship. Soundscapes (`harbour-temple`, `street-bells`, `kampong-morning`) and effects (`playChime`, `playStampThunk`) are synthesised with the Web Audio API in `src/services/audio/`. Prepared narration MP3s, when generated, live in `public/audio/narration/`.
